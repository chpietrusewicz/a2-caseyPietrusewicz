## Apartment Necessity Tracker

The tracker is used to help users keep a record of what items are kept in their apartment or home. The user can select from different categories to group their items, select how often the item is used, and view a current status of the item. Quantities can be updated which adjusts the status in real time, informing the user when they need to go to the store and get certain items.

A grid layout was used for the project. 2 columns were used to display the form and the table next to each other. The header was kept out of the grid.

## Technical Achievements

- **Tech Achievement 1**: Single-Page App
    Both the form and the table are displayed in the main index.html page. A renderTable function is called each time data is added to the table, deleted from the table, or modified, allowing the table to always be up to date. The function is also called on window load, so the data displays when the page is opened. Refreshing is not needed to display the correct data.
- **Tech Achievement 2**:  Modify Data
    For this achievemnt, I made it so the quantity of an existing item can be updated. I chose this functionality because it would allow the app to be used as a live tracker. Clicking on the "Adjust Quantity" button will give the user a prompt where they can enter the new desired quantity.
